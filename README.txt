This is the code for manuscript "Stable Nonconvex Statistical Estimation for Simultaneous Low-rank and Smooth Data", 
including:
1. demo_test.m (proposed sLRMF v.s. baseline LRMF)

2. simulations
- verification_linear_convergence.m 
- verification_smoothness_dependent_errors.m

note that we also provide 
- simulations_smoothness_dependent_errors_for_other_methods.m 
in the other_simulations file for the simulation experiments on the dependency relationship between the statistical estimation error and the smoothness level of the underlying matrix for a seris of low-rank and/or smooth regularized methods

3. applications to images
- demo_image_denoising.m
- demo_image_sensing
- demo_image_inpainting 
- demo_image_outlier removal

* run with MATLAB 2021a or higher version *
